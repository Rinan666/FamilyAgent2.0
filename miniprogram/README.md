# FamilyAgent Mini Program

This directory contains the native WeChat mini program MVP.

## Before running

1. Set the backend mini-app env vars:
   - `WECHAT_MINI_APP_APP_ID`
   - `WECHAT_MINI_APP_APP_SECRET`
2. Update `utils/config.js` with your API domain.
3. Import this folder into WeChat DevTools.

## Current scope

- WeChat login
- Create or join a family
- Family chat
- Family memories
- Settings and privacy entry
