# 最新推进目标

**日期**：2026-06-05  
**阶段**：Phase 1 AI 家教 MVP 公网 Beta  
**唯一目标**：让 3-5 个真实种子家庭完成一次完整数学学习闭环。

完整闭环：

```text
注册 -> 数学诊断 -> AI 批改 -> 查看结果/错题 -> AI 讲题 -> 家长看到反馈
```

## 当前判断

项目已经具备小范围真实试用条件：

- 前端、后端、AI 服务和基础设施可以本地一键启动。
- 邀请码注册、登录态、诊断优先路径已经接入。
- 题库、出题、批改、测试记录、错题本、BKT 学力更新已经形成主链路。
- 错题记录已从临时推断升级为正式数据表。
- 测试记录详情已能展示题目、学生答案、参考答案和分数。

当前最重要的不是继续扩功能，而是验证真实家庭是否愿意完成并复用这一条学习链路。

## P0：本周只做这些

| 目标 | 验收标准 |
|------|----------|
| 发放 3 个种子家庭试用 | 每个家庭完成注册，或明确记录卡点 |
| 跑通至少 1 次真实学习闭环 | 孩子完成诊断、批改、查看错题、AI 讲题 |
| 修复真实用户最大阻塞 | 每天只修影响闭环最大的 1 个问题 |
| 完成最小家长反馈摘要 | 家长能看懂薄弱点、错题和下一步建议 |
| 补最小使用日志 | 能判断用户卡在打开、注册、诊断、批改还是讲题 |

## P1：Beta 前补齐

| 目标 | 说明 |
|------|------|
| 题库资源化增强 | 支持批量导入/生成、分页、标签、知识点、题型、难度筛选 |
| 诊断出题策略 | 按知识点覆盖、难度梯度、题型配比生成诊断卷 |
| 错题本体验 | 展示最近错误答案、来源测试、参考答案、批改结果 |
| 会话历史恢复 | 用户能查看或继续历史讲题会话 |
| AI 使用上限 | 控制公网 Beta 成本和异常调用 |
| 前端关键测试 | 覆盖登录、测试提交、API 客户端、SSE 消息追加 |

## 暂不做

- 不扩展 Growth、Mirror、语音日记或家族知识库。
- 不急着做 App、小程序或多学科。
- 不公开大规模投放。
- 不同时重构前端、后端和 AI 服务。
- 不再新建零散“下一步”文档；下一步只维护本文件。

## 下一次决策点

当 3-5 个真实家庭完成试用后，只看三个问题：

1. 孩子是否能独立完成一次诊断和讲题？
2. 家长是否理解产品价值，并愿意让孩子再用一次？
3. 最大阻塞来自题库、批改、讲题质量、界面流程，还是部署稳定性？

根据这三个答案决定下一轮迭代。
