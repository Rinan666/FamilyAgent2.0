# 最新推进目标

**日期**：2026-06-06
**阶段**：Phase 2 方向校准：家族记忆与软资产传承、权限共享、家族经验与镜像 Agent
**唯一目标**：让 10-30 个真实用户/家庭，优先是有传承意识的中产家庭、喜欢记录的新生代用户，并补充少量高端家庭样本，验证 FamilyAgent 的非题库价值：成员愿意记录真实日记，愿意按权限共享给家人，长者经验能被沉淀，镜像 Agent 能帮助家族成员更了解彼此。

验证闭环：

```text
创建家庭 -> 邀请成员 -> 写一条家族日记 -> 设置可见范围 -> 录入一条家族经验 -> 镜像 Agent 基于授权记录对话 -> 家庭成员获得更具体的理解和建议
```

## 当前判断

项目不应继续把题库、作业批改和拍照答疑作为战略中心。成熟教育竞品已经在这些领域建立了极强优势，FamilyAgent 难以通过追赶题库数量和解题效率形成壁垒。

当前更重要的是验证 FamilyAgent 的家族记忆与软资产传承价值：

- 家庭成员是否愿意持续写日记、事件记录或给家人的话。
- 用户是否理解并信任“仅自己可见 / 全家可见 / 照护者可见”的授权边界。
- 家族长者的经验、故事、家风、创业/投资教训和提醒是否愿意被录入。
- 家长是否认可体态、牙齿、视力、睡眠、运动、屏幕时间等成长守护提醒。
- 喜欢记录的新生代用户是否愿意把 FamilyAgent 当作“家庭版长期记忆系统”，而不只是个人日记工具。
- 家庭成员是否愿意通过镜像 Agent 更好地理解某个成员的表达方式、价值观和经历线索。
- AI 家教、作业批改和错题记录是否能作为成长观察信号，而不是产品主线。

## 可裁剪功能判断

现在不建议直接删除教育工具代码，但建议继续隐藏或降级以下入口：

- **数学诊断**：不再作为家庭主入口，只保留为学习状态的可选信号源。
- **作业批改**：不追求拍照答疑和批改效率，后续只在能生成成长观察时使用。
- **错题本**：不单独推动用户维护，可作为家庭陪伴 AI 的历史学习线索。
- **学习报告**：不再独立强调，未来合并进家庭周报或成长守护摘要。
- **题库/知识库**：仅管理员可见，用于后台资源维护。

真正需要继续投入的是“低门槛输入”和“高价值输出”：日记、长者经验、镜像参考、家庭周报和权限边界。

## 暂不作为战略重点

- 不与作业帮、猿辅导等产品竞争海量题库。
- 不把拍照答疑做成主要卖点。
- 不继续投入复杂教材同步和诊断策略，除非它服务于成长观察。
- 不做医疗诊断，只做提醒、记录、科普和就医建议。
- 不公开大规模投放，先验证 10-30 个真实用户/家庭是否认可新价值。
- 不把诊断、作业批改、错题本、学习报告放回普通用户主导航，除非它们明确服务于家庭记忆或成长守护。

## 下一次决策点

当 10-30 个真实用户/家庭完成试用后，只看五个问题：

1. 家庭是否愿意录入真实经验、故事或提醒？
2. 家庭成员是否愿意记录日记并授权部分内容给家人？
3. 镜像 Agent 是否真的帮助家人更了解某个成员，而不是让人觉得冒犯或不可信？
4. 家长是否觉得成长守护提醒提供了普通教育产品没有的价值？
5. 最大阻塞来自录入门槛、隐私担忧、AI 整理质量、镜像边界，还是界面流程？
