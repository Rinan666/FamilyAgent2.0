# 路线图

更新时间：2026-06-08

## 当前阶段

**Phase 2：家族记忆与软资产传承 MVP 验证**

唯一目标：让 10-30 个真实用户/家庭验证 FamilyAgent 的非题库价值。

验证闭环：

```text
创建家庭
-> 邀请成员
-> 写一条家族日记
-> 设置可见范围
-> 录入一条家族经验
-> 镜像 Agent 基于授权记录对话
-> 家庭成员获得更具体的理解和建议
```

## 当前判断

项目不应继续把题库、作业批改和拍照答疑作为战略中心。成熟教育竞品已经在这些领域建立强优势，FamilyAgent 难以通过追赶题库数量和解题效率形成壁垒。

真正需要验证的是：家庭成员是否愿意记录真实内容，是否信任“仅自己可见 / 全家可见 / 照护者可见”的边界，长者经验是否愿意被沉淀，镜像 Agent 是否帮助家庭成员更理解彼此。

## 当前产品边界

Phase 2 只关注：

- 家族日记、重要事件、自我复盘和给家人的话。
- 家族经验、长者故事、家风价值观、健康提醒和人生教训。
- 镜像 Agent：基于授权记录做风格参考、价值观参考和自我复盘辅助。
- 成长守护：体态、牙齿、视力、睡眠、运动、屏幕时间、情绪和沟通观察。
- 家庭陪伴 AI：自由对话、学习陪伴和家庭记忆问答。
- 授权 RAG：后端先做权限过滤，再做文本或向量相关性排序。

Phase 2 暂不关注：

- 与成熟教育产品竞争海量题库。
- 拍照答疑作为核心卖点。
- 复杂教材同步和大型诊断策略。
- 医疗诊断或健康结论。
- 小程序、App 或大规模公开投放。
- 让普通用户围绕诊断、作业批改、错题本和学习报告建立主要使用习惯。

## 功能裁剪原则

当前采用“软裁剪”：

- 侧栏和首页不再展示数学诊断、作业批改、错题本和学习报告。
- 相关路由、后端模型和 AI 能力暂时保留，避免破坏历史数据和依赖。
- 后续只有当这些功能能转化为家庭日记、成长守护或家庭陪伴 AI 的辅助信号时，才继续投入。
- 如果真实家庭几乎不使用这些学习工具，下一轮再删除普通用户路由或合并到家庭陪伴 AI。

## 下一次决策点

当 10-30 个真实用户/家庭完成试用后，只看五个问题：

1. 家庭是否愿意录入真实经验、故事或提醒？
2. 家庭成员是否愿意记录日记并授权部分内容给家人？
3. 镜像 Agent 是否真的帮助家人更了解某个成员，而不是让人觉得冒犯或不可信？
4. 家长是否觉得成长守护提醒提供了普通教育产品没有的价值？
5. 最大阻塞来自录入门槛、隐私担忧、AI 整理质量、镜像边界，还是界面流程？
