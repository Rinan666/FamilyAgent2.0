# 项目计划

## 当前阶段

**Phase 1：AI 家教 MVP（数学）**  
当前进度约 85%，目标是支持真实种子家庭完成一次完整学习闭环。

## 项目边界

Phase 1 只关注：

- 用户注册、登录、邀请码。
- 数学题库和知识点。
- 诊断测试、AI 批改、测试记录。
- 错题本和 AI 讲题。
- 学力评估和家长可理解的反馈。

Phase 1 暂不关注：

- 多学科。
- 语音日记。
- 家族知识库。
- 镜像 Agent。
- 小程序或 App。
- 大规模部署。

## 已完成

| 模块 | 状态 |
|------|------|

| 前端 | Next.js Dashboard、登录注册、题库、测试、错题本、学力评估、AI 家教 |

## 里程碑

| 里程碑 | 完成标准 |
|--------|----------|
| M1 本地闭环 | 开发者本地可以完整跑通注册、测试、批改、错题、讲题 |
| M2 种子试用 | 3-5 个真实家庭完成试用并反馈 |
| M3 Beta 稳定 | 关键路径稳定，具备最小日志、成本控制和家长报告 |
| M4 多学科准备 | 题库结构和能力模型能支持其他学科接入 |

## 工程原则

- Java 负责业务和持久化。
- Python 负责 AI、数学验证和 BKT 计算。
- 前端负责交互和状态展示。
- 不让前端信任用户传入的 `userId`，以后端登录态为准。
- 有正式数据模型时不靠前端临时推断。
- 每次迭代优先修真实用户遇到的最大阻塞。
