# 长期规划

## 产品愿景

FamilyAgent 的长期身份是家族 Agent，而不是单一 AI 家教。AI 家教只是第一个入口，用来沉淀学习数据、互动数据和家长信任。

长期目标是形成三条能力线：

| 能力线 | 说明 |
|--------|------|
| Tutor | 学习辅导、测评、讲题、错题、能力追踪 |
| Growth | 日记、习惯、任务、成长事件、作品记录 |
| Mirror | 长期记忆、人格建模、镜像对话、家族传承 |

## 阶段路线

| 阶段 | 目标 | 关键能力 |
|------|------|----------|
| Phase 1 | 数学 AI 家教 MVP | 诊断、批改、错题、讲题、学力评估 |
| Phase 1.5 | 多学科与题库资源化 | 多标签题库、批量导入/生成、诊断策略 |
| Phase 2 | 个性化成长 | 日记、任务、成长事件、家长观察、报告 |
| Phase 3 | 镜像 Agent | 长期记忆、隐私授权、人格/偏好建模 |
| Phase 4 | 家族知识系统 | 家族知识库、代际经验、成员协作 |

## 能力模型

顶层采用“德智体美劳”作为家庭教育总框架，但不强行给所有维度打分。

| 顶层维度 | 数据来源 |
|----------|----------|
| 德 | 家长观察、任务记录、日记、事件复盘 |
| 智 | 学科题库、诊断测试、BKT/IRT、讲题记录 |
| 体 | 运动、习惯、健康任务、打卡 |
| 美 | 作品、表达、审美活动、创作记录 |
| 劳 | 家务、实践任务、责任行为、家庭协作 |

短期只给“智 -> 数学”显示真实分数。其他维度先展示为框架和待接入状态，避免制造伪精确数据。

## 数据与隐私原则

- 未成年人数据默认私有。
- 学习记录、日记、家族知识、镜像训练数据需要分层授权。
- 家长报告优先输出“证据 + 趋势 + 建议”，避免绝对化人格判断。
- 镜像 Agent 必须有明确授权、可撤回、可查看、可删除机制。

## 技术演进

| 方向 | 当前 | 长期 |
|------|------|------|
| 数据库 | 单 PostgreSQL + 逻辑隔离 | 分区、分片、少数高隐私家庭独享库 |
| AI | LiteLLM + FastAPI | 多模型路由、成本控制、质量评估 |
| 记忆 | 会话和测试记录 | 事件记忆、标签、向量检索、权限过滤 |
| 部署 | 本地/小范围公网 Beta | 云服务器、监控、备份、灰度发布 |
| 客户端 | Web | 小程序、移动端、语音入口 |

## 长期判断

FamilyAgent 的壁垒不在于单次讲题，而在于：

1. 长期学习与成长数据沉淀。
2. 家庭语境下的个性化反馈。
3. 家族知识和成员记忆的安全传承。
4. Tutor、Growth、Mirror 之间逐步增强的闭环。
