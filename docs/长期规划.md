# 长期规划

## 产品愿景

FamilyAgent 的长期身份是面向有传承意识家庭的家族记忆与软资产 AI，而不是单一 AI 家教。它的核心使命是让家风、价值观、长者经验、人生教训和家庭记忆不断裂，让家庭成员更理解彼此，并在下一代成长过程中提前看见那些容易被忽略的长期风险。

早期用户应以愿意记录的新生代和有传承意识的中产家庭为主；高净值、企业家家庭和家族办公室是后续高客单价、高隐私、私有化部署分支。

AI 家教不是最终护城河，而是早期入口和成长信号来源。真正的壁垒来自每个家族独有的长期记忆、长者经验、成员画像、隐私授权、软资产整理方法和代际传承关系。

## 长期能力线

| 能力线 | 说明 |
|--------|------|
| Heritage | 家族经验、长者故事、家风价值观、人生踩坑教训和代际传承 |
| Growth Guard | 体态、牙齿、视力、睡眠、运动、屏幕时间、情绪和习惯等成长守护 |
| Mirror | 长期记忆、成员画像、沟通建议、镜像对话和家庭理解 |
| Tutor | 学习陪伴、测评、讲题、错题和学习状态信号 |

## 阶段路线

| 阶段 | 目标 | 关键能力 |
|------|------|----------|
| Phase 1 | AI 家教与家庭空间 MVP | 登录、家庭、角色、AI 对话、基础学习入口 |
| Phase 2 | 家族记忆与软资产传承 MVP | 家族日记、经验录入、AI 整理、成长提醒、镜像 Agent、权限授权 |
| Phase 3 | 家族成员画像与软资产周报 | 成员状态、沟通建议、授权摘要、家族经验复盘、下一代成长提醒 |
| Phase 4 | 镜像 Agent 与代际传承 | 长期记忆、长者经验视角、故事线、可撤回授权、访谈式录入 |
| Phase 5 | 高隐私家族数据系统 | 分层权限、独立存储、备份、长期托管和必要合规记录 |

## 能力模型

顶层仍可采用“德智体美劳”作为家庭教育总框架，但不强行给所有维度打分，也不制造伪精确判断。

| 顶层维度 | 数据来源 |
|----------|----------|
| 德 | 家风价值观、家族经验、长者观察、事件复盘、责任行为 |
| 智 | 学习记录、讲题会话、作业状态、阅读与表达 |
| 体 | 体态、牙齿、视力、睡眠、运动、屏幕时间 |
| 美 | 作品、审美活动、表达、创作记录 |
| 劳 | 家务、实践任务、家庭协作、长期责任 |

短期只输出“证据 + 趋势 + 建议”，不对人格、健康或亲子关系做绝对化判定。

## 成长守护原则

- 不做医疗诊断，只做提醒、记录、科普和就医建议。
- 对体态、牙齿、视力、睡眠等问题，只基于记录和通用建议提醒家长进一步观察。
- AI 输出应降低焦虑，避免恐吓式判断。
- 涉及未成年人情绪、隐私和敏感经历时，默认更保守。
- 家长报告应展示授权范围内的摘要，不暴露孩子全部内心内容。

## 数据与隐私原则

- 未成年人数据默认私有。
- 家族经验、成长记录、成员画像和镜像训练数据需要分层授权。
- 每条家庭记忆都应能看到来源、可见范围和用途。
- 授权必须可撤回，数据必须可删除。
- AI 读取家庭知识库前，必须经过后端权限过滤。
- 关键操作需要保留必要记录：修改权限、删除记录、访问未成年人数据。它不是当前 MVP 的核心功能，但在高隐私托管和私有化部署阶段会成为信任基础。

## 技术演进

| 方向 | 当前 | 长期 |
|------|------|------|
| 数据库 | 单 PostgreSQL + 逻辑隔离 | 分层权限、分区、少数高隐私家庭独享库 |
| AI | LiteLLM + FastAPI | 多模型路由、长期记忆检索、质量评估 |
| 记忆 | 会话、测试、家庭成员 | 事件记忆、经验卡、成员画像、向量检索 |
| 权限 | 登录态 + 家庭成员关系 + 照护授权 | 细粒度授权、可撤回、可删除、必要操作记录 |
| 部署 | 本地/小范围公网 Beta | 云服务器、监控、备份、私有化部署、灰度发布 |
| 客户端 | Web | 小程序、移动端、语音访谈入口 |

## 长期判断

FamilyAgent 的壁垒不在于单次讲题，而在于：

1. 家风价值观、家族经验、创业/投资教训和长者故事的持续沉淀。
2. 孩子成长风险的长期、温和、非诊断式守护。
3. 家庭语境下的成员画像和沟通建议。
4. 家族记忆在严格授权下被 AI 理解和调用，并逐渐形成家庭私有数据壁垒。
5. Heritage、Growth Guard、Mirror 与 Tutor 之间逐步增强的闭环。
