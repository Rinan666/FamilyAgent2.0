## 启动方式

### 公网 Beta 推荐启动方式

公网访问建议让前端跑生产模式。之前在 `next dev` 下出现过公网表单点击后停留在 `login?` 的问题，生产模式已经验证更稳定。

先启动基础设施、后端和 AI 服务：

```powershell
cd D:\FamilyAgent
.\start-all.bat
```

如果需要手动启动前端，使用：

```powershell
cd D:\FamilyAgent\frontend
npm run build
npm run start
```

然后启动固定公网 Tunnel：

```powershell
cloudflared tunnel --config C:\Users\JianDan\.cloudflared\config.yml run familyagent-beta
```

### 本地开发启动方式

本地改代码调试时可使用开发模式：

```powershell
docker compose up -d
cd D:\FamilyAgent\backend
mvn spring-boot:run -Dspring-boot.run.profiles=dev

cd D:\FamilyAgent\ai-service
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

cd D:\FamilyAgent\frontend
npm run dev
```

## 后续云服务器切换

当前方案是 Cloudflare Named Tunnel，把公网域名转发到本机服务。

后续如果切换到云服务器方案，可以继续沿用同一批域名：

```text
familyagent.cn
app.familyagent.cn
ai.familyagent.cn
```

切换时只需要把 Cloudflare DNS / Tunnel / Nginx 代理调整到云服务器，用户入口可以保持不变。
