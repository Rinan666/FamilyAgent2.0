# AI家教功能规划

**日期**：2026年6月4日  
**适用范围**：FamilyAgent 的 AI家教 Tutor 模块  
**定位**：明确 AI家教在 Phase 1 的当前目标，以及面向 Growth / Mirror 阶段的长期演进方向。

---

## 一、产品定位

AI家教不是简单的搜题、刷题或聊天机器人，而是一个具备教学判断、学习记忆和主动陪伴能力的教育 Agent。

短期内，它要先完成数学学科的家教 MVP：能从题库抽题或生成测试题，评估孩子的学力，并提供两种讲题风格。

长期看，它应逐步具备更强的自主性、多模态输入输出、主动对话、语音交互和长期记忆能力，并与镜像 Agent 共享部分长期学习与人格画像数据。

---

## 二、Phase 1 当前目标

当前阶段的 AI家教目标应聚焦在“数学学力评估 + 讲题闭环”，避免过早扩散到过多辅助功能。

### 2.1 必须具备的核心能力

1. **从题库抽题**
   - 根据知识点、难度、年级、学科从已有题库抽取题目。
   - 支持自适应抽题：优先选择学生最近发展区内的题目。
   - 当前题库需要继续补充测试样例，尤其是能产生错题记录和学力变化的测试数据。
   - 题库应从 AI家教对话页拆出，成为独立的“题库/知识资源”模块，详见 `docs/题库与知识资源规划.md`。
   - 当前题库先服务数学测试与讲题，数据结构需要保留多学科、标签化导入和未来家族知识传承的扩展空间。

2. **独立测试模块与测试内容生成**
   - 由 AI 根据知识点、年级、题型、难度生成题目。
   - 生成题目需要尽量结构化，包含题干、答案、步骤、解析、知识点和难度。
   - 数学正确性应优先交给 sympy 或确定性校验逻辑，而不是完全信任 LLM。
   - 测试功能应从 AI家教对话窗口中分离，作为独立功能模块存在。
   - 测试模块应能解析用户的测试要求，包括题目数量、题目范围、知识点、难度、题型和输出格式。
   - 测试内容可以输出为在线页面文本、结构化 JSON、PDF 文件或未来其他文件格式。

3. **评估孩子学力**
   - 学生提交答案后，AI 进行批改。
   - 批改结果应包含是否正确、步骤评分、错误分析和学习建议。
   - BKT 更新知识点掌握概率，形成学力档案。
   - 前端学力仪表盘展示掌握度、薄弱点、最近发展区。

4. **两种讲题风格**
   - **引导式讲题**：苏格拉底式教学，通过问题和提示引导学生自己思考，不直接给最终答案。
   - **快速答案式讲题**：当学生明确需要快速获取答案时，直接给出解法、步骤和结论。
   - 两种风格应可由用户显式切换，也可未来由 Agent 根据场景判断。

### 2.2 当前辅助能力

错题本属于 Phase 1 的辅助闭环功能，但不是 AI家教 MVP 的第一优先级。

当前判断：

- 错题本前端页面已经存在。
- 更关键的缺口是测试题库和测试记录不够充实，导致错题本没有足够真实数据承载。
- 错题本后续应服务于“复习与再练习”，而不是替代核心的抽题、讲题、批改、学力评估闭环。

---

## 三、Phase 1 优先级调整

为了完成第一阶段目标，近期优先级建议如下：

| 优先级 | 事项 | 说明 |
|--------|------|------|
| P0 | 充实测试题库 | 补充数学题、知识点覆盖、难度梯度和可产生错题的测试数据 |
| P0 | 独立测试模块 | 解析测试要求，生成测试内容，支持在线文本/PDF/结构化数据输出 |
| P0 | 两种讲题风格 | 引导式与快速答案式需要在交互上清晰可用 |
| P1 | 错题本数据联动 | 让测试记录和错题记录能自然流入错题本 |
| P1 | 会话记忆雏形 | 保存 AI家教对话历史，为后续长期记忆打基础 |
| P2 | 错题本体验打磨 | 筛选、复练、跳转讲题等体验优化 |

## 四、未来 AI家教能力

长期的 AI家教应从“响应式工具”升级为“有记忆、有主动性、有多模态能力的学习伙伴”。

### 4.1 自主性

未来 AI家教应具备一定主动性：

- 根据学生近期学习表现，主动发起复习提醒。
- 根据薄弱知识点，主动推荐练习。
- 根据连续错误、长时间停顿或学习状态变化，主动调整教学策略。
- 在合适时机主动总结阶段性学习表现。
- 在家长授权下，主动生成学习报告或提醒家长关注某些问题。

### 4.2 多模态输入

未来 AI家教需要支持多种输入方式：

- 文本输入：学生直接输入问题、答案、解题步骤。
- 图片输入：拍照上传题目、草稿、作业页。
- 语音输入：学生直接说出问题、思路或困惑。
- 手写输入：识别草稿纸上的算式、图形和步骤。

多模态输入的目标不是炫技，而是降低孩子提问和表达思路的门槛。

### 4.3 多模态输出

未来 AI家教也应支持多种输出方式：

- 文本讲解：结构化讲题、步骤解析、总结。
- 数学公式：稳定渲染 LaTeX / KaTeX。
- 图形辅助：几何图、函数图、数轴、流程图。
- 语音输出：未来有语音能力后，AI家教可以主动说话。
- 互动式输出：题目卡片、选择题、填空、步骤拖拽、知识点图谱。

### 4.4 主动语音对话

当语音功能成熟后，AI家教应能像真实家教一样主动说话：

- 开始学习时主动问候并询问目标。
- 做题卡住时主动提示。
- 学生答错后用语音温和解释。
- 阶段结束时主动总结。
- 支持家长模式下的语音学习反馈。

语音交互需要注意节奏、语气和情绪安全，不能给学生造成压迫感。

### 4.5 长期记忆

AI家教需要逐步具备较强的记忆能力，为 Mirror Agent 和 Growth 模块打基础。

记忆对象包括：

- 学生的知识点掌握情况。
- 学生常见错误类型。
- 学生偏好的讲题风格。
- 学生的学习能力变化。
- 学生的学习风格，例如喜欢例子、图示、公式推导或快速结论。
- 学生在 AI家教对话中透露的性格特性，例如耐心程度、自信程度、焦虑点、表达方式。
- 学生与 AI家教的历史对话。
- 未来 Growth 模块中的日记、反思和成长记录。

这些记忆应分层存储：

| 记忆类型 | 示例 | 用途 |
|----------|------|------|
| 短期上下文 | 当前题目、当前对话轮次 | 支持当前讲题连贯性 |
| 学习档案 | 掌握概率、错题、错误类型 | 支持学力评估和自适应抽题 |
| 偏好记忆 | 喜欢引导式还是快速答案式 | 支持个性化教学 |
| 性格画像 | 容易焦虑、需要鼓励、表达谨慎 | 支持更合适的互动方式 |
| 长期成长记录 | 日记、阶段总结、学习变化 | 支持 Mirror Agent 和成长分析 |

### 4.6 与镜像 Agent 的关系

AI家教与镜像 Agent 不应割裂。

AI家教会产生大量关于学生学习状态、表达方式、性格特性和成长轨迹的数据，这些数据未来可以成为镜像 Agent 的重要输入。

但需要明确边界：

- AI家教主要服务学习任务。
- Mirror Agent 主要服务长期人格、记忆和成长模拟。
- AI家教产生的数据进入 Mirror Agent 前，应经过授权、筛选和隐私控制。
- 学生和家长应能查看、修改、删除长期记忆。

---

## 五、隐私与安全原则

AI家教未来会记录大量敏感数据，因此必须从早期就建立隐私边界。

基本原则：

- 最小化采集：只记录实现教学和成长所必要的信息。
- 明确授权：长期记忆、性格画像、日记关联需要用户明确授权。
- 可解释：用户应知道 AI 记住了什么，以及这些记忆如何影响教学。
- 可删除：用户可以删除对话、画像、日记和长期记忆。
- 分级可见：学生、家长、家族成员之间的数据权限需要严格区分。
- 生产环境不应依赖 fail-open 鉴权策略。

## 六、阶段边界

### Phase 1：数学 AI家教 MVP

目标：

- 抽题 / 生成题目。
- 独立测试模块：根据题目数量、范围、难度生成测试内容。
- 测试内容可先支持在线文本和结构化 JSON，后续支持 PDF 文件。
- 学生完成测试。
- AI 批改。
- BKT 学力评估。
- 引导式讲题。
- 快速答案式讲题。
- 基础会话记录。
- 错题本作为辅助复习功能。

### Phase 1.5：增强型 AI家教

目标：

- 多学科支持。
- 更完整的测试题库。
- 更稳定的会话记忆。
- 更清晰的教学风格切换。
- 初步主动提醒。

### Phase 2：个性化成长联动

目标：

- 语音输入。
- 日记与成长数据进入长期记忆。
- 家族知识库与学习记录关联。
- 学习报告与成长报告联动。

### Phase 3：镜像 Agent 联动

目标：

- AI家教长期对话数据进入镜像建模。
- 学习风格、性格特性、成长轨迹成为 Mirror Agent 的一部分。
- 支持更长期、更个性化的陪伴式学习。

---

## 七、当前结论

第一阶段不应把重点放在继续扩展错题本，而应优先完成：

1. 充实数学测试题库。
2. 将测试功能从 AI家教对话窗口中分离，形成独立测试模块。
3. 打通测试生成、答题、批改、BKT 更新、学力展示闭环。
4. 明确支持引导式和快速答案式两种讲题风格。
5. 保存基础会话历史，为长期记忆做准备。
6. 让错题本自然承接真实测试数据，而不是单独成为主线功能。
