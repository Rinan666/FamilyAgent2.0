## 二、已完成功能清单

### 2.1 基础设施

- ✅ Docker Compose 一键启动（PostgreSQL 16 + pgvector、Redis 7、RabbitMQ 3.13、MinIO）
- ✅ 12 张数据库表（新增 `tenant_storage_routes`，为未来分片/独享库预留）
- ✅ 多租户隔离字段：`family_id`、`visibility`、`permission_scope`
- ✅ 数据库迁移脚本：`scripts/migrate-multitenant-storage.sql`
- ✅ `start-all.ps1` 自动执行初始化脚本和多租户迁移脚本
- ✅ 15 个知识点种子数据 + 20 道初中数学示例题目
- ✅ GitHub Actions CI（Java Maven、Python Ruff、Frontend ESLint + TypeScript）

### 2.2 Java 后端（Spring Boot 3.3）

- ✅ 用户模块：注册（BCrypt）、登录（Sa-Token JWT）、获取用户信息
- ✅ 家族模块：CRUD、邀请码加入、角色权限（OWNER/ADMIN/MEMBER）
- ✅ 题库模块：知识点树查询、题目分页/筛选、题目录入、批量导入、自适应抽题
- ✅ 题库标签：PostgreSQL `TEXT[]` 类型处理、标签筛选、GIN 索引
- ✅ 评估模块：学力档案 CRUD、BKT 更新（委托 Python 计算）、最近发展区、雷达图数据、独立测试记录提交
- ✅ 错题查询：按单题分数识别错题，不再只按整张测试总分判断
- ✅ 会话模块：创建、消息记录、结束存档
- ✅ 安全：Sa-Token 拦截器守卫所有 `/api/**` 路由
- ✅ 用户级数据接口：新增 `/me` 形态接口，后端以登录态为准，不信任前端传入的 `userId`
- ✅ 家族隔离：提交测试携带 `familyId` 时校验当前用户必须属于该家族
- ✅ AI 服务客户端：SSE 流代理、批改、出题、BKT 更新
- ✅ 统一响应格式 + 全局异常处理 + 32 个错误码
- ✅ 15 个单元测试（UserService 8个 + AssessmentService 7个）

### 2.3 Python AI 服务（FastAPI）

- ✅ 讲题Agent：苏格拉底式引导教学，SSE 流式输出
- ✅ 讲题风格：支持 `guided` 引导式和 `direct` 快速答案式
- ✅ 批改Agent：步骤级评分、7 类错误识别、结构化 JSON 输出
- ✅ 出题Agent：批量生成（4 种题型 × 5 级难度）、变式题生成
- ✅ 数学验证引擎：sympy 符号计算、答案验证、步骤验证
- ✅ BKT 知识追踪引擎：贝叶斯更新、时间衰减遗忘、ZPD 识别、自适应抽题
- ✅ LLM 客户端：LiteLLM 多模型、DeepSeek 适配、自动降级、2 次重试
- ✅ Token 鉴权中间件：调 Java 后端验证 Sa-Token，fail-open 策略
- ✅ 18 个单元测试（math_executor 8个 + knowledge_tracker 10个）

### 2.4 前端（Next.js 16 + TypeScript）

- ✅ 登录/注册页面（表单验证、错误提示、API 集成）

- ✅ 家教页面：SSE 流式聊天、KaTeX 公式渲染、引导式/快速答案式切换、自由输入题目

- ✅ 题库/知识资源页面：手动录入、JSON 批量导入、学科/知识点/难度/题型/标签筛选
- ✅ 错题本页面：错题列表、测试历史、知识点/难度筛选、跳转练习
- ✅ 学力评估页面：雷达图（Recharts）、统计卡片、知识点掌握列表、动态用户 ID 和知识点名称

## 四、当前可运行的完整流程

```
用户注册/登录
    → 创建/加入家族
    → 进入题库/知识资源页录入或导入题目
    → 独立测试模块生成测试内容
    → 学生答题 → AI批改（步骤级评分 + 错误分析）
    → 保存测试记录 → BKT更新学力档案
    → 学力评估仪表盘（雷达图 + 知识点掌握度）
    → 错题本展示单题错误记录
    → AI家教按引导式或快速答案式讲题
```
