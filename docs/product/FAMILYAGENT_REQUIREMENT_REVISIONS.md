# FamilyAgent 需求修订清单

> 版本：V1.0  
> 用途：统一 FamilyAgent 的产品表述口径，区分“当前已实现能力”“产品愿景”和“后续演进方向”  
> 更新时间：2026-07-02

---

## 1. 使用说明

本文档用于修正 FamilyAgent 旧有需求表述中容易“把愿景写成现状”“把角色写成真人”“把方向写成已完成能力”的部分。修订原则如下：

1. 保留产品初心：精神财富、少走弯路、家族内部可信参考。
2. 尊重代码现实：镜像不等于真人，AI 主动性不是当前基线，深度理解不是已完成结果。
3. 明确层次：区分当前能力、阶段目标和长期愿景。

---

## 2. 修订清单

| 编号 | 原说法 | 存在问题 | 建议新说法 |
|---|---|---|---|
| RR-001 | FamilyAgent 是一个家族聊天 AI / 家族陪伴 AI | 过于弱化产品本质，容易被理解成普通聊天工具 | FamilyAgent 是一个面向家族传承与理解的 AI 系统，用于沉淀、共享和调用家族成员的经历、近况、价值观与洞见，逐步形成可持续传承的精神资产。 |
| RR-002 | 帮助家族成员少走弯路 | 结果表达过强，缺少机制说明 | 通过沉淀家族内部真实经历、价值判断和可迁移策略，FamilyAgent 为成员在迷茫、选择和成长场景中提供更真实、更贴近、更可代入的参考，从而帮助减少不必要的试错。 |
| RR-003 | 默认模式是家族智库 | 容易被理解成强知识系统，和当前实现不完全一致 | 默认模式是家族智库型 Agent，以家族记忆库为基础，沉淀并调用家族成员的近况、经历、价值观和洞见，为对话提供家族上下文支持。 |
| RR-004 | AI 会自动保存有价值的信息 | 与当前代码不一致，当前为确认式保存 | 系统支持 AI 辅助判断内容是否值得沉淀，并通过确认式保存流程将其写入记忆体系；同时也支持用户手动录入和编辑。 |
| RR-005 | 家族成员会共享近况 | 缺少权限边界，容易被理解为默认全共享 | 系统支持在权限控制前提下共享成员近况，家族成员可通过被授权的记录、记忆与对话上下文了解彼此近期状态。 |
| RR-006 | 近况就是最近的情况 | 定义过于模糊 | 在 FamilyAgent 中，近况指可被共享、可回顾、可帮助他人理解某个成员当前生活状态的流水记录，包括最近一周、一月、一年的事件、变化与阶段性状态。 |
| RR-007 | 真实成员就是镜像 AI | 风险过大，镜像不等于真人身份本身 | 镜像 AI 是基于真实成员授权记录与家族上下文生成的视角模拟，用于帮助理解该成员可能的表达方式、价值排序与思考习惯，但不等同于该成员本人，也不能替代其作出现实承诺。 |
| RR-008 | 用户可以通过镜像深入理解某个人 | 把结果写成系统保证 | 系统通过共享近况、保存记录和镜像式对话，帮助用户更好地理解某位成员的近况、经验与价值观，但不保证形成完整、无偏差的深度理解。 |
| RR-009 | 精神成员模式就是人生导师 | 容易被理解为权威导师或成熟教练系统 | 精神成员是基于用户设定和材料构建的精神角色，通过稳定遵循设定的视角化回应，为用户提供参考、启发和陪伴，而不是提供事实性权威结论。 |
| RR-010 | 精神成员无论如何都应该忠于设定 | 可作为设计目标，但不能写成绝对实现承诺 | 精神成员的设计目标是尽可能稳定地遵循用户设定的人设、价值倾向与表达风格，在材料不足时也以克制方式保持角色一致性。 |
| RR-011 | 希望家族成员人人使用它 | 这是愿景，不是当前阶段事实 | 长期愿景是让家族成员普遍参与记录、共享与理解；当前阶段优先目标是让产品创建者本人持续使用，并形成高质量冷启动内容。 |
| RR-012 | 非面对面也能互相深入了解 | 仍属于结果性承诺 | FamilyAgent 旨在帮助家族成员在非面对面场景下增进对彼此近况、经历与价值观的了解，并为进一步理解创造基础。 |
| RR-013 | 这是一个家族精神财富系统 | 方向正确，但过于抽象 | FamilyAgent 当前是一套家族精神财富的基础操作系统：先实现记录、保存、共享、召回和对话调用，再逐步演进到更强的理解、参考与传承能力。 |
| RR-014 | 迷茫时获取家族内部处理当前迷茫课题的应对经验作为参考 | 基本正确，但边界不够清楚 | 用户在迷茫、反思和做选择时，可与 Agent 对话，获得基于家族授权记录与沉淀内容的参考视角、经验片段和可迁移策略，而非被系统直接替代作决定。 |
| RR-015 | 最近一周、一月、一年的事情，家族成员共享信息 | 缺少权限边界和“共享的是记录”这一层 | 系统支持成员在权限控制前提下共享阶段性近况，使家族成员能够通过授权记录了解彼此近期状态与变化。 |
| RR-016 | 后续会提高 AI 的主动性 | 没问题，但要明确不是现状 | 当前基线以用户触发为主；后续版本将探索更主动的 AI 能力，例如主动识别高价值片段、建议沉淀、推荐相关家族参考内容。 |
| RR-017 | 基线已经做好了，已经部署上线了 | 从代码只能确认可部署与已形成基线，不能单凭 repo 证明全面成熟稳定 | 产品已形成可部署运行的基线架构，并已进入实际使用阶段；系统稳定性、运维观测与健康检查能力仍在持续完善中。 |
| RR-018 | 家族成员人人使用它，彼此间在非面对面情况下也能互相进行深入的了解，包括近况和价值观 | 混合了愿景、当前能力和结果性承诺 | FamilyAgent 的长期愿景是，让家族成员通过持续记录和权限化共享，逐步沉淀可被后代调用的精神财富，并在非面对面场景下增进对彼此近况、经历与价值观的理解。 |

## 3. 建议配套使用方式

建议在以下场景统一采用本修订清单中的新口径：

- 产品需求文档
- README 和项目介绍
- 精神成员 / 镜像成员相关设计文档
- 毕业设计 / 课程设计中的需求分析与产品说明
- 对外介绍、汇报、答辩与演示文稿

---

## 4. 推荐总述话术

如需用一句话统一描述当前 FamilyAgent，可采用：

> FamilyAgent 是一个面向家族传承与理解的 AI 系统，支持将个人与家庭范围内有价值的经历、近况、价值观和洞见沉淀为可持续保存和权限化共享的精神资产，并通过家庭 Agent、真实成员镜像和精神成员等方式在对话中提供参考与理解支持。
