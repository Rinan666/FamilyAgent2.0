# 题库与知识资源规划

**日期**：2026年6月4日  
**适用范围**：FamilyAgent 的题库、测试生成、AI家教参考资料与未来家族知识传承资源  
**定位**：把题库从 AI家教对话页拆出，建设为独立、可分类、可导入、可扩展的统一资源池。

---

## 一、当前问题

AI助教页面不适合直接罗列题库。

原因：

1. AI助教页面的核心任务是讲题、追问和互动，不应承担题库管理。
2. 题库规模变大后，在聊天页展示全部题目会干扰学习流程。
3. 题库下方的题目输入框容易造成误解：用户最后仍需要在对话输入框重新输入题目。
4. 测试生成需要稳定题源，题库应该作为测试模块和 AI家教的参考资源，而不是聊天窗口里的附属列表。

因此，题库需要独立成模块。

---

## 二、近期目标

Phase 1 仍以数学 AI家教 MVP 为主，近期题库建设不追求一次性完成完整知识管理系统，而是先满足测试与讲题闭环。

近期需要完成：

1. 独立题库页面。
2. 支持手动录入题目。
3. 支持 JSON 批量导入题目。
4. 支持按学科、知识点、难度、题型、标签筛选。
5. AI家教页面不再直接罗列全量题库。
6. 测试生成模块从题库抽题，题库成为测试内容来源。
7. AI家教可以把题库内容作为讲题和答疑参考。

当前阶段的题库数据结构应至少包含：

| 字段 | 说明 |
|------|------|
| `subject` | 学科，例如数学、语文、英语、科学、家族传承 |
| `grade` | 年级或阶段 |
| `kpId` | 知识点 ID，可为空 |
| `type` | 题型，例如选择、填空、计算、证明 |
| `difficulty` | 难度 1-5 |
| `content` | 题干、选项、图形等结构化内容 |
| `answer` | 答案、步骤、解析 |
| `tags` | 多标签，用于知识点、来源、用途、主题分类 |
| `source` | 来源，例如手动录入、AI生成、导入 |

---

## 三、题库与 AI家教的边界

题库不是 AI家教页面的一部分，而是 AI家教、测试生成和学力评估共享的资源底座。

边界如下：

| 模块 | 职责 |
|------|------|
| 题库/知识库 | 管理题目、标签、来源、分类、导入 |
| AI家教 | 针对某道题讲解、追问、批改思路 |
| 测试生成 | 根据测试要求从题库抽题或生成测试 |
| 学力评估 | 根据答题结果更新掌握度 |
| 错题本 | 承接测试和练习中的错误记录 |

题库页面负责“资源管理”，AI家教页面负责“教学互动”。

---

## 四、多模式上传规划

近期先支持：

1. 手动录入。
2. JSON 批量导入。

后续扩展：

| 上传方式 | 用途 |
|----------|------|
| PDF 上传 | 导入试卷、讲义、教材片段 |
| 图片上传 | 拍照录入题目或手写内容 |
| OCR 解析 | 从图片和扫描件识别题干、答案、解析 |
| Word/Markdown 导入 | 批量导入整理过的资料 |
| AI 自动拆题 | 从文档中识别题目、答案、知识点和标签 |
| 家族知识录入 | 录入长辈技能、人生经验、处世心法和家族故事 |

---

## 五、多标签分类规划

题库需要支持多维标签，而不是只按数学知识点存储。

标签维度包括：

| 维度 | 示例 |
|------|------|
| 学科 | 数学、语文、英语、科学 |
| 年级/阶段 | grade7、小学高年级、成人经验 |
| 知识点 | 一元一次方程、函数、阅读理解 |
| 难度 | 基础、提升、竞赛、易错 |
| 题型 | 选择、填空、计算、证明、问答 |
| 来源 | 手动录入、AI生成、教材、家族访谈 |
| 用途 | 测试、练习、讲题参考、家族传承 |
| 家族知识主题 | 技能、处世心法、人生事件、价值观 |

标签需要能被测试生成、AI检索、错题复习和未来 Mirror Agent 复用。

---

## 六、未来家族传承知识

题库未来不应只处理学校学科问题。

FamilyAgent 的长期目标中，题库/知识库也应承载家族精神财富，包括：

1. 长辈的技能和经验。
2. 处世心法。
3. 对人生重要事件的思考。
4. 家族故事、选择、遗憾和教训。
5. 家族成员擅长的手艺、职业技能和学习方法。
6. 能传给后代的价值观、判断力和生活智慧。

这些内容未来可以成为 Growth 和 Mirror Agent 的长期输入，让系统不只是辅导作业，也能帮助家庭保存和传承更深层的经验。

---

## 七、阶段边界

### Phase 1

优先完成数学题库、测试抽题、手动录入、JSON导入、标签筛选。

### Phase 1.5

扩展多学科题库，支持更完整的导入和题目审核流程。

### Phase 2

引入文档、图片、OCR、AI 自动拆题，开始沉淀家族知识资源。

### Phase 3

题库/知识库与 Mirror Agent 深度联动，支持长期记忆、家庭经验检索和个性化传承。

---

## 八、当前代码推进原则

当前实现应遵循：

1. 先把题库从 AI家教页面拆出。
2. 先服务测试生成和 AI讲题参考。
3. 数据结构保留多学科和多标签扩展接口。
4. 不在 Phase 1 过早实现完整家族知识管理系统。
5. 但命名、标签、来源字段和导入方式要为未来扩展留空间。
