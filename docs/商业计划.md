# FamilyAgent 商业计划

## 定位

FamilyAgent 是一个 **面向有传承意识家庭的家族记忆与软资产 AI 系统**。

它帮助家庭记录、整理、授权共享并活化家族记忆、长者经验、人生教训、成员理解和下一代成长观察。

FamilyAgent 不是更强的 AI 家教，而是一个更懂这个家庭的 AI 长辈、家庭记录员和记忆检索系统。

## 目标用户

早期不要只押注高净值家族。更现实的首批用户是两类：

| 用户 | 为什么适合早期验证 |
|------|--------------------|
| 有传承意识的中产家庭 | 重视孩子成长、长辈经验、家风延续和家庭关系 |
| 喜欢记录的新生代用户 | 已经习惯日记、长文、相册整理、自我复盘和个人知识管理 |

高净值家庭、企业家家庭、家族办公室仍然重要，但更适合作为后续高客单价分支：私有化部署、访谈整理、长期托管、家族经验库建设。

商业单元应是 **家庭/家族空间**，不是单个学生账号。

## 核心痛点

1. 家庭记忆会自然消失：很多故事只存在于饭桌、聊天、老照片和某个长辈的记忆里。
2. 经验记录了也不会被使用：日记、相册、聊天记录容易堆积，关键时刻很难被召回。
3. 长辈不愿意写，年轻人没时间整理：产品必须支持三句话经验、语音、访谈和 AI 自动整理。
4. 家庭共享不是越透明越好：日记、情绪、评价和成长观察必须可授权、可撤回、可删除。
5. 通用 AI 不懂这个家庭：FamilyAgent 的价值来自家庭长期私有记忆、关系和权限边界。

## 解决方案

| 能力 | 价值 |
|------|------|
| 家族 Agent | 对话中判断是否值得保存，并整理成日记、经验或观察 |
| 家族日记 | 保存成员经历、复盘、重要事件和给家人的话 |
| 家族经验库 | 沉淀长辈建议、家庭故事、家风价值观、健康提醒和人生教训 |
| 镜像 Agent | 基于授权记录做风格和价值观参考，但明确不是本人 |
| 成长观察 | 记录体态、牙齿、视力、睡眠、运动、屏幕时间、情绪和沟通等信号 |
| 授权 RAG | 先按权限过滤，再做向量/文本召回，只把相关记忆放进 AI 上下文 |
| 家庭周报 | 让记录产生可见回报：趋势、提醒、长者经验引用和建议行动 |

产品的核心不是“保存更多”，而是：

> 让家庭记忆在正确的时间，被正确的人，以合适的方式重新看见。

## 为什么现在做

- AI 已能低成本完成总结、归档、检索、问答、风格参考和语气转换。
- 年轻一代已经接受数字记录和 AI 工具，但缺少面向家庭关系和代际传承的产品。
- 中等收入家庭对教育、健康、亲子关系、养老和精神消费的付费意愿正在增长。
- 数字遗产、个人知识管理、AI 陪伴和家庭服务都在发展，但多数产品没有家庭空间、权限和长期记忆。

## 商业模式

MVP 阶段：

- 家庭空间订阅
- AI 自动整理额度
- 家庭周报 / 成长观察报告
- 长辈访谈整理
- 照片故事整理
- 家族记忆初始化服务

成熟阶段：

- 私有化部署
- 高隐私数据托管
- 家族办公室 / 私人银行渠道合作
- 家族经验库建设服务
- 镜像 Agent 与长期记忆增值服务
- 家族传承报告和下一代成长档案

## 竞争与差异化

| 对比对象 | 他们强在哪里 | FamilyAgent 差异 |
|----------|--------------|------------------|
| 作业帮、猿辅导 | 题库、拍照答疑、解题效率 | 不竞争解题效率，只把学习作为成长信号 |
| Notion / Obsidian | 笔记和知识管理 | 面向家庭成员、权限、代际关系和 AI 活化 |
| 日记 / 相册 App | 记录方便 | 能整理为经验、召回关键记忆、支持家庭共享 |
| 通用 ChatGPT | 通用能力强 | 不拥有家庭长期私有记忆和授权关系 |
| 家族办公室 | 高端人工服务 | 可作为软资产数字化工具补位 |

## MVP 要验证的问题

找 10-30 个真实用户/家庭，验证四周：

| 周期 | 目标 |
|------|------|
| 第 1 周 | 建家庭空间，录入 5-10 条基础记忆 |
| 第 2 周 | 长辈贡献 3 条经验，年轻人写 3 条日记 |
| 第 3 周 | 使用家族 Agent 和镜像 Agent 做真实对话 |
| 第 4 周 | 输出家庭摘要，访谈是否愿意继续用或付费 |

核心问题：

1. 一个家庭里是否能出现至少一个持续记录者？
2. 长辈是否愿意用三句话、语音或照片讲出经验？
3. 家族 Agent 是否比通用 AI 更懂这个家庭？
4. 用户是否愿意查看每周家庭摘要或成长提醒？
5. 用户是否愿意为家庭空间、隐私存储和 AI 整理付费？

## 最大风险

| 风险 | 应对 |
|------|------|
| 用户不持续录入 | 语音、访谈、照片触发、AI 自动保存、家庭群聊入口 |
| AI 不够懂这个家 | 多级索引、时间权重、权限 RAG、家庭周报、关键场景触发 |
| 隐私不被信任 | 权限可解释、可删除、可撤回、可私有化部署、镜像不冒充本人 |
| 价值太抽象 | 每周输出具体提醒、家族经验引用、成长观察变化和下一步行动 |
