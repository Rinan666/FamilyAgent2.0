# 商业计划

## 一句话定位

FamilyAgent 是一个 **面向高净值家族的软资产管理与传承 AI 系统**。

它不管理财富本身，而是帮助家族管理财富背后的经验、家风、判断力、关系理解和下一代成长观察。

## 项目背景

高净值家族通常已经有较成熟的财富管理工具，例如信托、保险、股权架构、税务筹划和家族办公室服务。但很多家族真正难以传承的，并不是物质资产，而是软资产：

- 家风和价值观；
- 长辈的人生经验；
- 创业、投资和经营中的教训；
- 处事原则和风险意识；
- 家族成员之间的理解；
- 下一代成长中的长期观察；
- 健康、体态、审美、教育方式和生活习惯。

这些内容重要但不容易被结构化记录，也很难被下一代持续理解和使用。

FamilyAgent 的机会在于：把这些家族软资产变成可以长期保存、授权共享、被 AI 调用的家族私有知识系统。

## 战略判断

FamilyAgent 不应该和作业帮、猿辅导等成熟教育产品竞争题库、拍照答疑和解题效率。

更有差异化的方向是：

**家庭长期记忆 + 家族经验传承 + 下一代成长守护 + 镜像 Agent + 隐私授权。**

项目核心壁垒不来自公开题库，而来自每个家族长期积累的私有数据、关系网络、经验记录和授权记忆。

## 目标客户

| 层级 | 用户 | 说明 |
|------|------|------|
| 核心客户 | 高净值家族、企业家家庭、重视家族传承的多代家庭 | 对家风、隐私、下一代培养和长期传承有强需求 |
| 早期测试用户 | 有孩子、有长辈、愿意记录家庭经验的中产家庭 | 用于验证真实使用场景和产品体验 |
| 长期大众市场 | 普通家庭 | 可扩展为家庭记忆、成长陪伴和经验传承工具 |

当前最适合的商业切入点是高净值家族，因为他们更愿意为隐私、长期保存、定制化服务、下一代培养和家族传承付费。

## 核心痛点

- 家族长者经验、教训、故事和价值观容易随着时间散失。
- 财富可以交接，但判断力、家风和风险意识很难自然传下去。
- 年轻父母容易忽略孩子成长中的长期问题，例如体态、牙齿、视力、睡眠、运动、情绪和沟通。
- 家族成员之间了解有限，很多关心停留在成绩、工作、生活安排等表层信息。
- 高净值家族对隐私和数据控制要求高，普通 SaaS 很难获得信任。

## 核心价值

| 对象 | 价值 |
|------|------|
| 长者 | 把人生经验、创业教训、家族故事和重要提醒系统留给后代 |
| 父母 | 记录下一代成长信号，获得更长期、更温和的成长提醒 |
| 子女 | 通过授权记录理解家族经验、价值观和前辈视角 |
| 家族 | 形成可持续积累、可授权共享、可被 AI 调用的家族软资产 |

## 产品主线

| 能力 | 说明 |
|------|------|
| 家族日记 | 记录成员日常、重要事件、自我复盘、成长观察和给家人的话 |
| 家族经验库 | 记录长辈经验、创业教训、家族故事、健康提醒、教育理念和人生建议 |
| 成长守护 | 关注体态、牙齿、视力、睡眠、运动、屏幕时间、情绪和习惯等长期风险 |
| 镜像 Agent | 基于授权记录做风格参考、价值观参考和自我复盘辅助，不冒充本人 |
| 成员画像 | 基于授权记录整理偏好、压力点、表达方式、沟通建议和变化趋势 |
| 权限授权 | 日记、照护记录、经验、画像进入 AI 前必须经过后端权限过滤 |
| 学习信号 | AI 家教、作业批改和错题记录只作为下一代成长观察的一部分 |

## 当前进度

项目当前处于 **MVP 原型验证阶段**，已具备在线体验能力。

已完成能力包括：

- 家族空间；
- 家族日记；
- 家族经验库；
- 成长守护记录和周报；
- 镜像 Agent；
- 动态亲属称呼；
- 照护授权；
- 授权记忆召回；
- 镜像画像授权过滤；
- 基础 AI 对话和家庭陪伴入口。

当前重点不是大规模商业化，而是验证目标用户是否认可“家族软资产传承 AI”这一方向。

## 商业模式

短期：

- 家族空间订阅；
- 高端家庭试用服务；
- 家族经验库搭建；
- 长辈访谈整理；
- 成长守护报告。

中长期：

- 私有化部署；
- 高隐私数据托管；
- 家族知识库建设；
- 家族传承报告；
- 镜像 Agent 增值服务；
- 家族办公室/财富管理机构合作。

## 风险与边界

- 高净值家族非常重视隐私，必须提供数据隔离、权限控制、可删除、可撤回和私有化部署可能性。
- AI 不能冒充本人，镜像 Agent 只能基于授权记录做参考。
- 成长守护不能输出医疗诊断，只能做提醒、记录、科普和就医建议。
- 系统不能输出法律、投资、医疗结论，只能整理经验和辅助思考。
- 早期最大风险不是技术，而是用户是否愿意持续录入家族数据。

## 验证指标

当前不追求大规模增长，先看小样本强信号：

| 指标 | 目标 |
|------|------|
| 家族经验录入意愿 | 3-5 个家庭中至少 2 个愿意录入真实经验或故事 |
| 家长价值表达 | 家长能说出“这个提醒我以前没注意到”或类似价值点 |
| 长者参与 | 至少一个长辈愿意贡献经验、故事或建议 |
| 镜像 Agent 接受度 | 用户觉得镜像参考有帮助，且不冒犯、不越界 |
| 隐私信任 | 用户能理解并认可授权边界 |

## 当前商业结论

FamilyAgent 的机会不是做更强的 AI 家教，而是做更懂这个家族的 AI。

它的护城河不在公开题库，而在家族长期积累的私有记忆、经验、关系和授权数据。

更准确的定位是：

**面向高净值家族的软资产管理与传承 AI 系统。**
