# 商业计划

## 一句话定位

FamilyAgent 是面向家庭的 AI 教育与成长平台。短期先用 AI 家教解决孩子数学学习闭环，长期沉淀为家族成员的学习、成长、知识传承和镜像 Agent。

## 用户痛点

- 家长没有足够时间、能力或预算持续辅导孩子。
- 孩子做题后缺少即时、耐心、可追溯的讲解。
- 家长难以看懂孩子真正薄弱在哪里。
- 家庭成长记录、家族知识和教育经验容易散失。

## 核心价值

| 对象 | 价值 |
|------|------|
| 孩子 | 随时获得讲题、批改、错题复习和个性化练习 |
| 家长 | 看懂孩子薄弱点、学习过程和下一步建议 |
| 家庭 | 长期沉淀成长记录、知识经验和成员画像 |

## 产品路径

| 阶段 | 产品形态 | 商业目标 |
|------|----------|----------|
| Phase 1 | 数学 AI 家教 MVP | 验证孩子愿意用、家长看得懂 |
| Phase 1.5 | 多学科与题库增强 | 提升复用频率和学习覆盖面 |
| Phase 2 | 成长记录与家族知识库 | 从学习工具升级为家庭成长系统 |
| Phase 3 | 镜像 Agent | 形成长期记忆和家族传承壁垒 |

## 商业模式

短期以家庭订阅为主：

- 免费试用：限制题量、讲题次数和历史保留。
- 家庭月费：解锁完整诊断、错题本、AI 讲题、家长报告。
- 高级套餐：多孩子、多学科、长期记忆、家族知识库。

中长期可扩展：

- 教育内容合作。
- 家庭成长报告。
- 高隐私家庭数据托管。
- 家族传承知识库与镜像 Agent 增值服务。

## PMF 验证指标

当前不追求大规模增长，先看小样本强信号：

| 指标 | 目标 |
|------|------|
| 完整闭环完成率 | 3-5 个家庭中至少 1-2 个完整跑通 |
| 二次使用意愿 | 家长愿意让孩子下次继续用 |
| 价值表达 | 家长能说出一个明确价值点 |
| 最大阻塞 | 能明确归因到题库、讲题、批改、流程或部署 |

## 主要风险

- 题库质量不足导致诊断价值不稳定。
- AI 批改和讲题质量不稳定。
- 家长报告不够直观，无法形成付费理由。
- 未成年人数据和隐私边界需要严格设计。
- AI 成本在公网试用后可能快速上升。

## 当前商业结论

FamilyAgent 现阶段不是先做“完整家族 Agent”，而是先用数学 AI 家教建立第一个真实、高频、可验证的入口。只要孩子愿意用、家长看得懂，后续 Growth 和 Mirror 才有数据基础和商业意义。
