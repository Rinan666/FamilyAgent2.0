# 数字图像处理大作业选题说明

**题目：基于人脸检测与特征聚类的家庭相册智能归档系统**

\---

## 一、用户要完成什么操作

用户（家庭成员）上传若干家庭照片后，系统自动完成：

1. 检测每张照片中的人脸位置
2. 提取人脸特征，将同一人的照片归为一组
3. 以"按人物分类"的相册视图呈现结果，用户可将分组标注为具体的家族成员

**核心价值**：不需要用户手动打标签，系统自动回答"这些照片里谁出现了多少次、都在哪些场合"。

\---

## 二、程序内部用了哪些图像处理技术

处理管线按顺序如下：

### 1\. 人脸检测

* 方法：Haar 级联分类器（OpenCV `CascadeClassifier`）
* 输入：原始 RGB 图像
* 输出：每张图中各人脸的边界框坐标
* 参数分析：`scaleFactor`（图像缩放步长）、`minNeighbors`（邻域过滤阈值）对检出率与误检率的影响

### 2\. 人脸预处理

* 灰度转换：降维，去除颜色干扰
* 直方图均衡化：统一不同光照条件下的亮度分布
* 人脸对齐（仿射变换）：以双眼坐标为基准，旋转+缩放至标准尺寸（如 64×64）
* 中间结果可视化：原图 → 灰度图 → 均衡化后 并排对比

### 3\. 特征提取（双方案对比）

|方案|方法|原理概要|
|-|-|-|
|A|Eigenfaces（PCA）|对人脸图像矩阵做主成分分析，取前 K 个特征向量构成"特征脸空间"，每张人脸投影为 K 维向量|
|B|LBP 纹理特征|以每个像素为中心，编码周围像素的相对大小关系，形成局部纹理直方图描述子|

参数分析：Eigenfaces 保留主成分数 K（10 / 20 / 50）对表示精度与聚类效果的影响。

### 4\. 人脸聚类

* 方法：DBSCAN（基于密度，无需预设人数，适合家庭场景人数未知的情况）
* 输入：每张人脸的特征向量
* 输出：聚类标签（同一人的照片归为同一簇，噪声点标记为"未识别"）

\---

## 三、最终结果如何展示和评价

### 展示

* **相册视图**：前端按聚类分组展示，每组附代表性人脸缩略图
* **标注框可视化**：原图上叠加检测到的人脸边界框
* **Eigenfaces 可视化**：展示前 8 个特征脸图像，直观理解主成分含义
* **t-SNE 降维散点图**：将高维特征投影到 2D，观察聚类分布是否清晰

### 定量评价

|指标|说明|
|-|-|
|人脸检测率 / 误检率|在测试集上统计漏检与误检数量|
|轮廓系数（Silhouette Score）|评估聚类紧密度与分离度，范围 \[-1, 1]，越高越好|
|重建误差|Eigenfaces 在不同 K 值下的图像重建均方误差（MSE）|

### 对比实验

* Eigenfaces 特征 vs LBP 特征：在同一批照片上分别聚类，比较轮廓系数
* 光照影响分析：正常光照 vs 逆光 / 暗光，两种特征的鲁棒性对比

\---

## 实现方案

* 语言 / 库：Python，OpenCV + scikit-learn + matplotlib
* 集成方式：作为独立 FastAPI 接口挂载到现有后端服务
* 核心接口：`POST /api/faces/cluster`，接收图片列表，返回分组结果
